# no02 — 迷った手は Claude に回す（差し戻しデモ）

YouTube「ずんだもんの実験道具箱」の JEV 回の続編（jev/no02「迷った手は、Claudeに回すのだ」）で使った、自作の問い合わせ受信箱です。
JEV が選んだ手のうち、確信度が線（0.65）に届かない手だけを Claude（`claude -p`）が決め、次の手はまた JEV に戻る、という分担を手元で動かせます。

> このフォルダも、動画と同じ中身を保つため、公開後は変更しません。

## 動画との対応

- 第1章「迷った手を、考えるAIへ回す」— 下の「仕組み」の分担
- 第2章「30件を流して、Claude を呼んだ手を数える」— `/batch` で30件を流す画面。上の「Claude 呼び出し n／M 手」が主メーター
- 第3章「1件に寄って、JEV に戻るまでを追う」— 受信箱の札を押すと、その件の手ごとの往復（JEV の確信度・行き先・Claude の選択）が出ます
- 第4章「自分の仕事に、線を1本引く」— 画面に出した分岐の数行は `escalation.py` の実物です（下の「分岐の数行」）

## 必要なもの

- Python 3.10 以上（標準ライブラリだけで動きます）
- JEV の API キー（各自で TypeSafe AI から取得）。`~/.config/jev/api-key` に1行で保存してください
  - キーはサーバーだけが読みます。ブラウザーや記録ファイル、Claude の子プロセスには渡しません
- Claude Code の `claude` コマンド。`claude -p` がログイン済みで使えること
  - 呼び方は `escalation.py` の `build_claude_argv()` で固定しています（モデル `claude-opus-5-5`・effort `high`・ツールなし・MCP なし）

## 起動

`no02/` の中で動かします。fixture の SHA256 は起動のたびに照合し、違えば起動しません（終了コード 2）。

```sh
cd no02
python3 server.py --port 8766 --escalation-definition v2 \
  --escalation-fixture fixture/inquiries.json \
  --escalation-sha256 41256ebb40da298f371a38299b9f72f0c14f38359e4273db972ab7d888533b03
```

- http://127.0.0.1:8766/batch?take=take01 — 差し戻しデモ。「開始」で30件を流します（`&autostart=1` を付けると開いてすぐ始まります）
- http://127.0.0.1:8766/api/health — 起動の確認（キーのファイルがあるか・fixture の SHA256・閾値・定義セット）

1回の起動で流せるのは1テイクだけです（テイク名は `take01` か `take02`）。もう一度流すときはサーバーを起動し直し、別のテイク名にするか、前の記録のフォルダを消してください（記録は上書きしない作りです）。
1テイクの呼び出しは JEV・Claude とも最大90回までに制限しています。JEV のエラー3連続・Claude のエラー2連続で止まります。

## 仕組み

1. 問い合わせを1件ずつ開き、決まった順の3手（担当 → 優先度 → 返信の型）を進める
2. 各手で、プログラムが画面の文字と押せるボタンを読み、JEV に1つ選ばせる（確信度つき）
3. 確信度が 0.65 以上なら、JEV の選んだボタンをプログラムが押して次の手へ
4. 0.65 未満なら、その手だけ Claude に回す。Claude には JEV と同じ画面の文字と候補だけを渡し、JEV の答えや確信度は渡さない
5. JEV は Claude を待たない。その件を「考え中」にして、次の件へ進む。Claude は同時3件まで考え、あふれた分は順番待ち
6. Claude が決めたら、プログラムがその件に戻ってボタンを押し、次の手はまた JEV に聞く
7. 3手が決まれば保存。Claude が「決められない（STOP）」と答えた件や、エラーの件は止める（押した操作は戻さない）

線を引くのはこちらです。0.65 は前回（no01）の線をそのまま使っただけで、よい値だと確かめたものではありません。

## 分岐の数行

行き先を分けるのはサーバー側の `escalation.py` だけです。画面（`batch.js`）はサーバーの返事に従って押すだけで、閾値の判定はしません。

- `THRESHOLD = 0.65`（39行目）— 線
- `gate()`（314行目）— `return 'jev' if confidence >= threshold else 'claude'`
- `Desk._run_step()` の中（811〜823行目）— `routed = gate(jev['confidence'])` のあと、`jev` ならそのまま決定、そうでなければ `self._hold(...)` で Claude の待ち行列に入れてすぐ返す
- `build_claude_argv()`（358行目）— `claude -p` の呼び方
- `Desk._worker()`（872行目）— Claude を同時3件まで動かす係

判断の定義（依頼文・手ごとの問い・候補の文）は `escalation.py` の `STEPS` と `STEP_REPLY` にあります。

## 記録

1テイクの記録（JEV・Claude の入出力、手ごとの判断、Claude の生の出力、集計）は `no02/evidence/escalation-v2/runs/<テイク名>/` に残ります。
`evidence/` はリポジトリの `.gitignore` で追跡しません。API キーや認証ヘッダーは保存しません。

## 注意

- 架空の問い合わせ30件（`fixture/inquiries.json`）を使ったデモです。動画の数字は、この画面・この30件を1テイク流した事前検証の値で、ほかのデータや別のテイクで同じになるとは限りません
- 正解表は入れていません。Claude が決めた手も、正しいとは限りません。人の代わりに、考えるAIの読みを1つ足しただけです
- 「保存」は画面の中だけで、外のサービスやデータベースには触れません
- 確信度は当たりの保証ではありません。線の上で決まった手は Claude に回らないので、読み違えていても気づけません
- Claude 側は `claude -p`（Claude Code の契約のログイン）で動き、呼ぶたびに課金される呼び方ではありません。JEV は使った分だけの従量課金です（2026年9月時点で、入力にだけ課金・出力は無料）
- 画面の書体は Noto Sans JP を想定していますが、フォントは同梱していません。無くても別の書体で表示されます
- 実測の時点: 2026年9月、モデル jev-1.13.0・claude-opus-5-5
