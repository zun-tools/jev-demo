# jev-demo — 「選ぶだけのAI」JEV で画面を動かすデモ

YouTube「ずんだもんの実験道具箱」の JEV 回（jev/no01）で使った、自作の問い合わせ管理画面です。
JEV（TypeSafe AI の判定モデル）が「次に押すボタン」を選び、押すのはふつうのプログラム、という輪っかを手元で動かせます。

> このリポジトリは動画と同じ中身を保つため、公開後は変更しません。

## 必要なもの

- Python 3.10 以上（標準ライブラリだけで動きます）
- JEV の API キー（各自で TypeSafe AI から取得）。`~/.config/jev/api-key` に1行で保存してください
  - キーはサーバーだけが読みます。ブラウザーや記録ファイルには出しません

## 起動

```sh
python3 server.py --port 8765
```

- http://127.0.0.1:8765/ask — 問い合わせ1通を JEV に1回だけ聞く画面（動画の第1章）
- http://127.0.0.1:8765/?operator=claude — 画面操作の比較デスク（動画の第3章）
  - 右の「JEVに任せる」は本物の API を呼び、JEV の選んだボタンをプログラムが押します
  - 左は人やエージェントが自分で操作し、その時間を測るためのレーンです（ボタンでエージェントが起動するわけではありません）

1回の起動で API 呼び出しは最大100回、1回の実行で最大12手までに制限しています。

## 仕組み（第3章のループ）

1. プログラムが画面の文字と、押せるボタンを読む
2. ボタンに番号（e1, e2, …）を付け、「完了／止める／該当なし」も選択肢に加えて JEV に聞く
3. JEV が1つ選ぶ（確信度つき）
4. プログラムが確かめる：確信度が 0.65 以上か、そのボタンが今の画面にあるか、同じ手の繰り返しでないか
5. 通ればプログラムが押して 1 に戻る。「完了」で終わり。確かめに落ちたら止まる（押した操作は戻さない）

## 注意

- 架空の問い合わせ5件を使ったデモです。「保存」は画面の中だけで、外のサービスやデータベースには触れません
- 動画で試したのはこの画面と依頼文だけです。ほかのサイトや依頼で同じように動くことは確かめていません
- 確信度は当たりの保証ではありません。止める線はこちらで引きます
- 公式は英語が主で、日本語は同等の精度ではないと書いています。自分の仕事で確かめてから使ってください
- 実測の時点: 2026年9月、モデル jev-1.13.0
